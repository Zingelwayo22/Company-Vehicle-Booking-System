# Company Vehicle Booking System

A web-based application developed to simplify company vehicle booking, approval, and fleet management. Employees can request vehicles for business trips, while administrators manage employees, vehicles, bookings, and vehicle inspections.

# Features

# Employee
- Secure login and authentication.
- Submit vehicle booking requests with dates, times, and business reasons.
- Check vehicle availability.
- View booking history and request statuses.
- Manage employee profile information.
- Cancel eligible bookings.

# Administrator
- Manage employee records.
- Register, update, and manage company vehicles.
- Upload individual vehicle images.
- Approve or reject vehicle booking requests.
- Monitor booking activity and statuses.
- Record vehicle inspections and vehicle condition.

# Technologies

- **Language:** C#
- **Framework:** ASP.NET MVC 5
- **Platform:** .NET Framework
- **Database:** Microsoft SQL Server
- **ORM:** Entity Framework Code First
- **Authentication:** ASP.NET Identity
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **IDE:** Microsoft Visual Studio
- **Version Control:** Git and GitHub

# How It Works

1. Employees log in to the system.
2. They submit a vehicle request, specifying the booking period and reasons.
3. The system checks availability and booking conflicts.
4. An administrator reviews and approves or rejects the request.
5. Employees track their booking statuses.
6. Administrators manage fleet information and record vehicle inspections.

# Getting Started

# Prerequisites
- Microsoft Visual Studio with ASP.NET development tools.
- A compatible .NET Framework Developer Pack.
- Microsoft SQL Server or SQL Server LocalDB.

# Setup
1. Clone or download this repository.
2. Open `CompanyVehicleBookingSystem.sln` in Visual Studio, if included. Otherwise, open the `.csproj` file.
3. Restore the required NuGet packages.
4. Configure the database connection string in `Web.config` for your local environment.
5. Apply Entity Framework migrations if required.
6. Build and run the application in Visual Studio.
